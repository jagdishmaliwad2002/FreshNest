# FreshNest Organics – E-commerce Landing Page

A modern, responsive homepage UI for an organic grocery store, built with plain HTML and CSS.

**Created by Jagdish Maliwad**

## Sections

- Top offer bar and sticky-style header with search, account, and cart
- Hero banner: "Good Food. Good Health. Better Life."
- Shop by Category
- Featured Products with price, discount, and Add to Cart
- Trust badges (100% Organic, Safe for You, Support Farmers, Fast Delivery, Easy Returns)
- Customer testimonials
- Mobile app download and newsletter signup
- Footer with links, contact details, and payment methods

## Getting Started

1. Put `index.html` and `README.md` in the same folder.
2. Open `index.html` in any modern browser. No build step or dependencies are needed.

## Tech Stack

- HTML5
- CSS3 (Grid, Flexbox, CSS variables)
- Google Fonts: Inter and Playfair Display (needs an internet connection)

## Customization

- **Images:** The product, category, hero, and avatar visuals are emoji placeholders. Replace them with `<img>` tags pointing to your own photos.
- **Colors:** Edit the CSS variables in the `:root` block at the top of the `<style>` tag (`--green`, `--orange`, `--cream`).
- **Content:** Product names, prices, reviews, and contact details are sample data. Update them directly in `index.html`.
